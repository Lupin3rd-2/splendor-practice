# 璀璨宝石练习

给不太会玩、又要去线下社交的人提前练手用的璀璨宝石（Splendor）练习页。

## 分享初衷

I 人到线下社交、玩这些游戏时，容易因为不会玩而尴尬。提前在这里练几把，到场会从容很多。

## 怎么用

- 在线直接玩：[璀璨宝石练习](https://lupin3rd-2.github.io/splendor-practice/splendor.html)
- 主练习页：打开 [`splendor.html`](./splendor.html)
- 参考与效率相关页面：`splendor-reference.html`、`splendor-efficiency.html`
- 数据文件：`splendor-data.json`、`splendor-cards.csv` 等

同目录里还有一个德州扑克练习页 [`texas-holdem.html`](./texas-holdem.html)，可一并使用。

## 说明

这是练习用页面，规则以线下实际玩法为准。
